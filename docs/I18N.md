# Тілдер: қазақша, орысша, ағылшынша

Интерфейс үш тілде: `kk` (әдепкі), `ru`, `en`. Тіл құрылғыда сақталады (`studenthub.v1` → `lang`), онбордингте
және «Баптаулар → Тіл» бөлімінде ауысады (Қаз / Рус / Eng).

## Қалай жұмыс істейді

Кодтағы жүздеген `tt('қазақша', 'русский')` шақыруы өзгерген жоқ. Ағылшыншасы — **қазақ мәтінімен кілттелген
сөздік**: `frontend/src/lib/i18n/en.ts`.

- `tt(kk, ru)` (`frontend/src/lib/i18n/index.ts` → `tr`): `en` болса сөздіктегі аударма; жоқ болса — орысшасы;
  қазақ мәтінінде кирилл әрпі болмаса (мысалы `SIVA`) — сол мәтін.
- Шаблон жолдар: `` tt(`${n} күн қалды`, …) `` кілті — `"{0} күн қалды"`. Жұмыс кезінде дайын қазақ жолы осы
  үлгімен салыстырылып, тесіктер ағылшыншаға көшеді: `"{0} {0|day|days} left"` (`{0|бір|көп}` — санға қарай сөз
  формасы).
- `L({kk, ru})`: өз `en` өрісі, сосын сөздік (кодтағы мәтіндер), сосын орысшасы. **API-ден келетін контент**
  (мүмкіндіктер, вакансиялар, іс-шаралар) тек kk/ru — ағылшын тілді студент оның орысшасын көреді, белгісіз.
- Сөздік — бөлек chunk, тек тіл `en` болғанда жүктеледі (қалған студенттерге бір байт та қосылмайды). Жүктелгенше
  ағылшынша орнына орысшасы тұрады.
- Күн мен ақша: `Intl` `en` локалімен (`November 5`, `1,500 ₸`). `<html lang>` — `en`.
- API тек kk/ru сөйлейді: ағылшын интерфейсі серверге `accept-language: ru` жібереді (`apiLang`), сондықтан
  сервер қателері мен бот орысша. Аккаунттағы `users.lang` те `ru` болып сақталады.
- Dev режимінде аудармасы жоқ жолдар консольге тізіммен шығады (`[i18n] … UI strings have no English entry`).

## Жаңа мәтін қосқанда

```bash
cd frontend
node tools/i18n-extract.mjs --missing     # аудармасы жоқ жолдар (бар болса exit 1)
node tools/i18n-translate.mjs             # жоқтарын OpenAI арқылы аударып, en.ts-ке жазады (бар жазбаны өзгертпейді)
node tools/i18n-extract.mjs               # tools/i18n-strings.json: барлық жұп kk/ru/en + файлдары (шолу үшін)
```

- `i18n-extract.mjs` TypeScript парсерімен табады: бірінші екі аргументі жол болатын шақыру (`tt`, `t`, `s`, …),
  `tr(lang, kk, ru)`, екі жолдан тұратын массив (`Pair`), `{ kk, ru }` объектісі (`en`-і жоқ).
- `i18n-translate.mjs` кілтті `OPENAI_API_KEY`-ден не `~/studenthub-platform/.secrets/prod.env` файлынан оқиды
  (ешқашан шығармайды), модель `OPENAI_MODEL` (әдепкі `gpt-4.1-mini`). Тесіктері сәйкес келмеген аударма
  қабылданбайды — оны қолмен жаз.
- Аударманы шолып шық: қысқа UI ағылшыншасы, өнім атаулары (SIVA, Telegram, Kaspi) өзгермейді.
- `npm run test:ts` ішіндегі `src/lib/i18n/en.test.ts` әр жұптың ағылшыншасы барын, тесіктердің сәйкестігін және
  ағылшыншада қазақ әрпі жоғын тексереді — жетіспесе CI құлайды.
- `e2e/i18n-en.spec.ts`: ағылшыншаға ауысып, басты бет, іздеу, күнтізбе, профильде қазақ әріптері (ӘҒҚҢӨҰҮҺІ)
  қалмағанын DOM бойынша тексереді (басқа тілмен белгіленген элементтер мен API контентінен басқа).

## Шектеулер

- Ашық портфолио беті (`/p/<slug>`) және сервердегі мета-тегтер (job/opportunity/event превьюі) kk/ru күйінде.
- Telegram боты мен серверлік хабарламалар — kk/ru (ағылшын тілді студентке орысша).
