# TAPSYRMA 06: Student Hub — амбассадор кабинеті және ортақ модерация кезегі

Бұл — бар жобаның жалғасы. 04 және 05 промпттар орындалған: аккаунттар, рөлдер, `lib/notify.js`, нақты іс-шаралар мен QR. Алдымен кодты зертте: `/api/content` (Google Sheets + `data/*.json`), `#/admin`, 05-промпттағы іс-шара құру.

Мақсат: әр университеттегі амбассадор командасы өз университетінің мүмкіндіктерін, іс-шараларын және пайдалы орындарын қоса алады, ал admin бәрін бір кезектен тексереді. Амбассадорлардың жұмысы көрінеді және бағаланады, бірақ олар күйіп кетпейді.

Ережелер: ажыратқыш `ambassador` (әдепкіде қосулы). Хабарламалар тек `lib/notify.js` арқылы. Амбассадорға «лайк/басу/жүктеу» сияқты бос тапсырмалар ЖОҚ — тек нақты пайдалы әрекеттер.

МАҢЫЗДЫ: кезең-кезеңмен жаса, әр кезеңнен кейін тоқтап, маған тексеруге бер.

## 1-КЕЗЕҢ — Амбассадор командалары
- Кестелер: `ambassador_terms` (user_id, university, role_in_team: lead/member, term_start, term_end, hours_per_week, ref_code UNIQUE, status: active/ended), `ambassador_applications` (user_id, university, motivation, hours_per_week, status, reviewed_by, reviewed_at)
- Әр университетте 1 жетекші (lead) + 2–3 мүше. Мерзімі — бір семестр, кейін ұзартуға болады
- `#/ambassador/apply` — өтінім формасы: университет, неге қалайды (300 таңба), аптасына қанша сағат бере алады (1–2 / 2–3 / 3–5). Өтінім admin кезегіне түседі
- Өтінім бекітілсе → рөл `ambassador`, `direct` хабарлама + кабинетке сілтеме

## 2-КЕЗЕҢ — Амбассадор кабинеті `#/ambassador`
- «Менің университетім»: студенттер саны, апталық белсенділер, сақталған мерзімдер саны, іс-шаралар мен қатысу (тек жиынтық сандар, жеке аттар жоқ; 5 адамнан аз топ «< 5» болып көрсетіледі — мысалы, факультет бойынша бөлгенде)
- «Қосу» батырмалары: мүмкіндік (грант/тағылымдама/байқау), іс-шара (05-промпт), пайдалы орын (асхана, баспахана, т.б. — бар «Жақын маңда» бөліміне)
- «Менің ұсыныстарым»: әр ұсыныстың күйі (тексерілуде / жарияланды / қайтарылды + себебі)
- Команда: мүшелер тізімі, мерзімі, апталық уәде еткен сағаты
- «Ресурстар»: `CONFIG.ambassadorResources` сілтемелері (нұсқаулық, постер үлгілері, іс-шара сценарийлері) — әзірге placeholder
- Амбассадордың жеке шақыру сілтемесі `?ref=amb_<ref_code>` және «маған қанша студент қосылды» саны — `users.referred_by` бойынша есептеледі (аналитикадан емес)

## 3-КЕЗЕҢ — Ортақ модерация кезегі (тек admin)
- Кесте `submissions`: id, kind (opportunity / place / market_report / mentor_application / employer_job / ...), payload JSONB, submitted_by, university, status: pending/approved/rejected, reason, reviewed_by, reviewed_at
- `#/admin/queue` — барлық кезек бір жерде, түрі бойынша сүзгі, ескісі бірінші
- Бекіту / қайтару (қайтарғанда себеп міндетті) → авторға `direct` хабарлама
- Бекітілген мүмкіндіктер мен орындар `/api/content` нәтижесіне қосылсын (Google Sheets пен дерекқорды біріктір; дерекқордағыларда `source = ambassador`)
- Студенттер де «Мүмкіндік ұсыну» арқылы ұсына алады (02-промпттағы Google Form орнына немесе қосымша) — олар да осы кезекке түседі. Автоматты жариялау ЖОҚ
- Бекітер алдында admin тексеретін шағын тізім: ресми дереккөз сілтемесі бар ма, ақы сұрамай ма, мерзімі дұрыс па
- Кейінгі промпттар (07, 08, 10) өз модерациясын осы кезекке қосады
- Шағымдарға ортақ ереже (08 және 10 осыны қолданады): «N шағымнан кейін жасыру» тек әртүрлі, кемінде 7 күндік аккаунттардан келген шағымдарды санайды; бірінші шағымда-ақ admin-ге `direct` хабар кетеді; admin шағымды негізсіз деп тапса, жазба автоматты қайта көрінеді

## 4-КЕЗЕҢ — Бағалау және күйіп кетпеу
- Университеттер арасындағы командалық рейтинг (жеке амбассадорлар емес): апталық белсенді студенттер саны және іс-шарадағы қатысу. Студенттерге де көрінеді — «университетіміз 3-орында»
- Семестр соңында admin амбассадорға сертификат береді: `#/certificate/<id>` беті — аты, университеті, мерзімі, атқарған жұмысы (қанша іс-шара, қанша жарияланған ұсыныс), тексеру сілтемесі. Басып шығаруға болатын стиль
- Жүктеме шегі: амбассадор аптасына уәде еткен сағаттан көп тапсырма алмайды. Кабинетте «Демалыс аптасы» (кідірту) батырмасы бар
- Мерзімі біткенде: «жалғастырасың ба?» сұрағы, жалғастырмаса — рөл `student`-ке қайтады, жасаған контенті орнында қалады

## Аяқтау
Тесттер: амбассадор тек өз университетінің статистикасын көреді; бөтен университетке контент қоса алмайды; бекітілмеген ұсыныс сайтта көрінбейді; қайтарылған ұсыныс авторына себебімен хабарланады; мерзімі біткен амбассадор кабинетке кірмейді. README-ге: «Амбассадорды қалай қабылдаймын» нұсқаулығы. Қорытындыла.
