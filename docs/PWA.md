# Интернетсіз жұмыс (PWA)

Student Hub бір рет интернетпен ашылғаннан кейін негізгі бөлімдері интернетсіз де ашылады. Бұл — сайт баяу не
«құлап» тұрғанда да (review F1) студент кестесін, картасын, билетін көре алуы үшін.

Файлдар:

| Файл | Не істейді |
|---|---|
| `public/sw.js` | Service worker. Қолмен жазылған, кітапханасыз, build қадамы жоқ — басынан аяғына оқуға болады |
| `public/offline.html` | Ешқашан ашылмаған бет интернетсіз сұралса көрсетілетін бет (kk/ru, тақырып пен тіл localStorage-тан) |
| `lib/pwa.ts` | `useOnline()`, worker-ді тіркеу, «жаңа нұсқа» күйі, `keepPagesOffline()` |
| `components/Pwa.tsx` | Тіркеу (`PwaRegister`), «Интернет жоқ» жолағы (`OfflineBanner`), «Жаңа нұсқа дайын — Жаңарту» (`UpdateBar`) |
| `lib/tickets.ts` | Іс-шара билеттерінің құрылғыдағы көшірмесі (localStorage `studenthub.tickets`) |
| `lib/config.ts` | `/api/config` соңғы жауабы localStorage `studenthub.config`-та сақталады |
| `next.config.ts` | `/sw.js` тақырыптары (`no-store`), `NEXT_PUBLIC_BUILD_ID` |

## Интернетсіз не ашылады

- **Қолданба қабығы**: `/`, `/map`, `/settings`, `/roadmap`, `/profile`, `/mine`, `/events`, `/search`,
  `/notifications`, `/saved`, `/services` — worker орнатылғанда бірден сақталады. Басқа кез келген бет бір рет
  ашылса сақталады (мысалы `/job/j2`).
- **Сабақ кестесі** — басты бетте (`/`), деректері кодта.
- **Кампус картасы** — `/map` және `public/campus-map.jpg`.
- **Студенттік QR** (Профиль → цифрлық студенттік) — құрылғыдағы профильден жасалады.
- **Үлгі іс-шаралардың билеті** — localStorage-та (`studenthub.v1`).
- **Дерекқордағы іс-шара билеті және QR**: студент `/event/<id>` бетін не «Менің тізімім»-ді интернетпен ашқанда
  API-дің жауабы (`GET /api/events/{id}`, `GET /api/events/my`) `studenthub.tickets`-ке жазылады, ал `/event/<id>`
  беті worker-ге сақтауға жіберіледі. Интернетсіз билет пен QR осы көшірмеден шығады, үстінде «Сақталған көшірме
  (күні)». API шақырулары өзгерген жоқ — тек жауап есте сақталады.
  Көшірме өшеді: шыққанда (`signOut`), аккаунт өшірілгенде, «Барлық деректі өшіру»-де, сервер «кірмеген» деп
  жауап бергенде, құрылғыға басқа аккаунт кіргенде, іс-шара біткеннен 2 күн өткенде.
- **Құрылғыдағы барлық дерек** (профиль, сақталғандар, жоспар, roadmap) — бұрыннан localStorage-та.

Интернет жоқта:
- әр экранның басында тегіс жолақ: «Интернет жоқ — сақталған деректер көрсетілуде» / «Нет интернета — показаны
  сохранённые данные»;
- `api()` бірден `offline` қатесін береді: «Интернет жоқ — бұл әрекетке интернет керек.» (ұзақ күтпейді);
- іс-шарада «Тіркелу», «Бас тарту» батырмалары өшірулі, пікір формасы мен `.ics` сілтемесі жасырын, түсініктеме
  жазылады; «Telegram арқылы кір» батырмасы өшірулі («Кіру үшін интернет керек»);
- ешқашан ашылмаған бет (мысалы `/job/j1`) не `/p/<slug>` → `offline.html` («Интернет жоқ», «Қайталау», сақталған
  бөлімдерге сілтемелер; интернет қайтса өзі қайта жүктеледі). Браузердің «динозавр» беті шықпайды.

## Кэш ережелері (`public/sw.js`)

| Сұраныс | Стратегия |
|---|---|
| Бет (navigate), `/api`, `/p` емес | Алдымен желі. Желі жоқ, 4 с-тан баяу не 5xx болса — сақталған көшірме. Сақталмаған болса — `offline.html` |
| `/_next/static/*` (хэшті build файлдары) | Алдымен кэш |
| `/fonts/*`, `/icons/*`, `/campus-map.jpg`, `/manifest.webmanifest`, түбірдегі суреттер | Кэштегіні бірден береді, фонда жаңартады |
| Google Fonts (`fonts.googleapis.com`, `fonts.gstatic.com`) | Сол сияқты |
| `/api/*` | **Ешқашан** — worker тіпті ұстамайды |
| `/p/*` (ашық портфолио, `no-store`) | **Ешқашан** сақталмайды; интернет жоқта тек `offline.html` |
| Router дерегі (`RSC: 1` тақырыбы не `?_rsc=`) | Тек желі; сәтсіз болса Next бетті толық жүктейді, оны worker сақталған беттен береді |
| `Authorization` тақырыбы бар, GET емес, басқа сайттар | Ұстамайды |

Қосымша:
- Бет кілті — тек жол (`/search?k=jobs` → `/search`), `/index.html` емес, `/`.
- Тек `200`, сол origin, redirect емес, `text/html` жауап сақталады.
- `Cache-Control: no-store` бет сақталмайды. Ерекшелік — сұраныс сайын рендерленетін, бірақ ішінде жеке дерек жоқ
  қабық беттер: `/event/`, `/job/`, `/opportunity/`, `/market/`, `/organize/`, `/plan/`, `/deck/`, `/match/`,
  `/certificate/`, `/employer/` (экран деректі клиентте жүктейді). Жаңа динамикалық бетке жеке дерек
  серверде қосылса — оны `SHELL_DYNAMIC` тізіміне ҚОСПА.
- Авторизация жауаптары `/api/auth/*`, `/api/me` — `/api` астында, сондықтан ешқашан кэштелмейді.

## Нұсқа және жаңарту

Кэш аттары: `studenthub-pages-<VERSION>-<BUILD>` және `studenthub-static-<VERSION>-<BUILD>`.

- `BUILD` — әр build-тің өз id-і (`next.config.ts`: `VERCEL_GIT_COMMIT_SHA`-ның 12 таңбасы, болмаса уақыт).
  Бет worker-ді `/sw.js?v=<BUILD>` деп тіркейді, сондықтан **әр деплой автоматты түрде жаңа worker орнатады**.
- `VERSION` — `public/sw.js` басындағы `const VERSION = 'v1';`. Worker-дің логикасын (ережелерді) өзгерткенде
  көтер: `'v1'` → `'v2'`. Build id өзгермей тұрса да (бір коммиттен қайта деплой) жаңарту шығады.
- Жаңа worker орнатылады, бірақ **күтеді**: экранда «Жаңа нұсқа дайын — Жаңарту». Студент басқанда ғана
  `SKIP_WAITING` жіберіледі, worker басқаруды алады, бет бір рет қайта жүктеледі. Бет өздігінен ешқашан қайта
  жүктелмейді. Ұзақ ашық тұрған вкладка (Telegram Mini App) жарты сағат сайын және көрінгенде жаңартуды тексереді.
- Жаңа worker белсенді болғанда `studenthub-` префиксті, бірақ ағымдағы емес кэштердің бәрі өшеді.
- Worker тек production build-те тіркеледі (`next dev`-те жоқ) және тек `https:` немесе `localhost`-та.

Worker-ді толық өшіру керек болса: `components/AppRoot.tsx`-тен `<PwaRegister />` алып таста және `public/sw.js`-ті
өзін-өзі өшіретін нұсқамен ауыстыр (`self.registration.unregister()` + кэштерді өшіру) — файлды жай өшірсең,
орнатылған worker-лер ескі кэшпен жұмыс істей береді.

## Орнатылуы (installable)

`app/layout.tsx` → `metadata.manifest: '/manifest.webmanifest'`. Манифестте `name`, `short_name`, `start_url: /`,
`display: standalone`, иконкалар 192 және 512 (`any`) және толық фонды `icon-maskable-512.png` (`maskable`).
Chrome `Page.getInstallabilityErrors` — бос (Playwright тексеруі).

## Тексеру

```bash
npx next build --webpack
API_ORIGIN=http://127.0.0.1:9 npx next start -p 3016   # API жоқ режим
```

DevTools → Application → Service workers / Cache storage; Network → Offline. Тексеру сценарийі (Playwright):
бір рет интернетпен ашу → `context.set_offline(True)` және серверді тоқтату (Playwright-тың offline белгісі
worker-дің өз сұраныстарына әрдайым жетпейді) → `/`, `/map`, `/settings`, `/roadmap`, `/event/<id>`, `/job/j1`, `/p/x`.

Билетті API-сіз тексеру: `/api/config` (`features.events: true`), `/api/me`, `/api/events/<id>` (`my.status:
"registered"`, `my.ticket`) жауаптарын Playwright `context.route` арқылы беріп, `/event/<id>`-ті интернетпен ашу —
билет UI арқылы `studenthub.tickets`-ке жазылады. Не тікелей localStorage-қа:
`{"v":1,"owner":42,"events":{"7":{"event":<DbEvent, my-мен>,"savedAt":"…"}}}` және `studenthub.config`.
