# «Мүмкіндік білесің бе? Ұсын» — Google Form

Әр тізімнің соңында «Мүмкіндік білесің бе? Ұсын» батырмасы тұрады. Ол `SUGGEST_FORM_URL` (сервердегі `.env`) сілтемесіне апарады. Форма жауаптары **бөлек бетке** түседі. Сен тексеріп, қолмен `opportunities` бетіне көшіресің. **Автоматты жариялау жоқ** — бұл алаяқтықтан қорғайды.

## Форманы құру (өзің)
1. forms.google.com → Бос форма. Атауы: «Student Hub — мүмкіндік ұсыну».
2. Баптаулар → «Email мекенжайларын жинау» — **өшірулі**. «Бір жауапқа шектеу» — өшірулі (аккаунт талап етпесін).
3. Өрістер:

| № | Сұрақ | Түрі | Міндетті |
|---|---|---|---|
| 1 | Мүмкіндіктің атауы | Қысқа жауап | иә |
| 2 | Түрі | Тізім: Тағылымдама / Грант, байқау / Академиялық ұтқырлық / Халықаралық бағдарлама / Жұмыс / Жеңілдік / Басқа | иә |
| 3 | Ұйым | Қысқа жауап | иә |
| 4 | Ресми сілтеме (https://…) | Қысқа жауап, тексеру: «Мәтін → URL» | иә |
| 5 | Өтінім қабылдаудың соңғы күні | Күн | жоқ |
| 6 | Мерзімсіз бе? | Құсбелгі | жоқ |
| 7 | Қала | Тізім (Астана, Алматы, … Басқа, Қашықтан) | жоқ |
| 8 | Қысқаша сипаттама | Ұзын жауап | жоқ |
| 9 | Бұл туралы қайдан білдің? | Қысқа жауап | жоқ |

Жеке дерек (аты, телефон) **сұралмайды**.

4. Жауаптар → «Таблицаға байланыстыру» → Student Hub кестесінде жаңа бет (мысалы `suggestions`).
5. «Жіберу» → сілтеме → `/opt/studenthub/.env`-те `SUGGEST_FORM_URL=...`, сосын `systemctl restart studenthub-api`.

## Тексеру тәртібі
- Сілтеме ресми ме (ұйымның өз сайты, университет, gov.kz)?
- Алдын ала ақша сұрамай ма?
- Мерзімі өтпеген бе?
Сосын жолды `opportunities` бетіне `status = draft` етіп көшір, толтыр, `published` қой. 10 минут ішінде сайтта шығады.
