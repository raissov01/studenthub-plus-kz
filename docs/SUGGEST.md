# «Мүмкіндік білесің бе? Ұсын» — сайттағы форма → админ кезегі

Google Form енді **керек емес**. Студент мүмкіндікті сайттың өзінде ұсынады, ұсыныс `/admin/queue` кезегіне түседі,
admin тексеріп (керек болса түзетіп) бекітеді — сонда ғана сайтта шығады. **Автоматты жариялау жоқ** — бұл
алаяқтықтан қорғайды.

## Студент жағы

1. Әр тізімнің соңындағы «Мүмкіндік білесің бе? Ұсын» батырмасы → «Мүмкіндік ұсыну» формасы.
2. Telegram арқылы кіру және деректерді өңдеуге келісім керек (кірмеген болса — кіру терезесі; келісім жоқ болса — келісім экраны).
3. Өрістер: түрі, атауы (kk міндетті, ru қаласа), ұйым, қысқаша сипаттама, **ресми сілтеме `https://…`**,
   соңғы күн (міндетті емес; өткен күн болмайды), қала, «қаржыландырылады», «ақы сұрамайды».
   Жеке дерек (телефон т.б.) сұралмайды.
4. Жіберілгеннен кейін «Менің ұсыныстарым» бөлімінде күйі көрінеді: қаралуда / жарияланды / қайтарылды (себебімен).
5. Шешім шыққанда авторға Telegram хабарламасы келеді.

Бұл жол **амбассадор ажыратқышына тәуелсіз**: `FEATURE_AMBASSADOR=false` болса да кез келген студент ұсына алады.
Белсенді амбассадордың ұсынысы өз университетіне байланады (`source: "ambassador"`), қалғандары — `source: "student"`.

API: `POST /api/submissions`, `GET /api/submissions/my` (`docs/api/ambassador.md`, «Ұсыныстар»; фронт тізімі —
`docs/api/admin-content.md`, «Студенттің «Мүмкіндік ұсыну» формасы»).

## Admin жағы: тексеру тәртібі

`/admin/queue` → `opportunity` түрі (ескісі бірінші). Әр ұсыныста шағын тізім (`checklist`) бар:

- Сілтеме ресми ме (ұйымның өз сайты, университет, gov.kz)? (`hasOfficialSource`)
- Алдын ала ақша сұрамай ма? (`noFee`)
- Мерзімі өтпеген бе? (`deadlineOk`)

Әрекеттер:

- **Түзету** — қате жазылған атау, орысша мәтін жоқ, қала не мерзім қате болса: `PATCH /api/admin/queue/{id}`
  (жіберу кезіндегі ережелермен тексеріледі; `audit_log`-қа `moderation_edit` болып жазылады). Тек `pending` күйінде.
- **Бекіту** — ұсыныс бірден жарияланады (`/api/content` → `opportunities`, `id = amb-<n>`, `source: "student"`),
  авторға «бекітілді» хабарламасы барады.
- **Қайтару** — себебін жазу міндетті (3–500 таңба); автор себебін Telegram-да және «Менің ұсыныстарымда» көреді.

Толық жазба керек болса (құжаттар, қадамдар, талаптар, байланыс) — ұсынысты бекітудің орнына `/admin/content`
редакторында жаңа жазба ретінде толтырып, ұсынысты себебін жазып қайтаруға болады («редакторға көшірілді»).

## Ескі Google Form

`SUGGEST_FORM_URL` айнымалысы енді қажет емес. Бұрынғы форма мен жауаптар парағын жауып қоюға болады;
фронт «Ұсын» батырмасын сайттағы формаға бағыттайды.
