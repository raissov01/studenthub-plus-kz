# Дизайнды жаңарту: бағыт, токендер, нәтиже

Негіз: `student-apps-research.md` (13 референс, App Store скриншоттарынан өлшенген). Түс отбасылары —
`palette-research.md`. Тұрақты ережелер: **ақ бет `#FFFFFF`**, flat (тұтас түс + 1px жиек), градиент / blur /
түсті көлеңке / эмодзи жоқ, WCAG AA (`node frontend/tools/contrast.mjs`), қазақ әріптері (ӘҒҚҢӨҰҮҺІ) Golos Text
400/600 мен Geologica 700 жиындарында бар (fontTools-пен тексерілді: cyrillic + cyrillic-ext бірге бәрін жабады).

## Екі нұсқа

| | A. «Hairline ақ» (Notion Calendar стилі) | B. «Ақ бет + пастель аралдар» (Todoist + Handshake) |
| --- | --- | --- |
| Идея | Бәрі ақ, тек 1px сызықтар, түс тек кішкене нүктелерде | Ақ бет, бейтарап жүйе; түс **иконка плиткаларында**, тегтерде, жаңалық карточкаларында; бір толы батырма |
| Түс мөлшері | экранның < 3%-ы | ~8–12%, бірақ тек белгі деңгейінде |
| Пайдасы | ең таза, ең «Notion» | «түс жетпейді» деген сезімге тікелей жауап; бөлімдер бір қарағанда ажырайды |
| Қаупі | қазіргіден де монохром — пайдаланушының «бірдеңе жетпейді» шағымы күшейеді | түс шуылға айналуы мүмкін → ереже: мәтін әрқашан бейтарап, түс тек плиткада |
| Студент контексті | күнтізбе/жоспар үшін жақсы, лента үшін құрғақ | Handshake/Kaspi сияқты каталог + лента, пайдаланушыға таныс |

**Таңдау: B.** Себебі: (1) сұраныстың өзі — «түсі жетпейтін сияқты»: A түсті азайтады; (2) зерттеуде ортақ ереже —
ақ бет + бір акцент + санат түсі шағын белгіде — B соны дәл орындайды; (3) бізде бес пастель отбасы бұрыннан бар,
бірақ лаванда бетте олар көрінбей қалған (барлығы бір реңкте). Ақ бетке ауысқанда олар «арал» болып шығады.

### Примитивтер

- **Header** — ақ, жиек тек скролда; тақырып 21px Geologica 700, сол жақта.
- **Секциялар** — блок арасы 28px, тақырып 19px, «Барлығын қарау» 13px/600 primary.
- **Тізім жолы** (Handshake анатомиясы) — 64px, 40px r12 плитка + атау 15/600 + мета 13 сұр + шеврон;
  бөлгіш **inset**, мәтіннен басталады (iOS/Telegram).
- **Түс иконкада** (Todoist) — топтағы бейтарап иконка плиткалары кезекпен violet → sky → mint → peach → rose;
  мағыналы плиткалар (`.ok`, `.bad`, `.sun`) өз түсін сақтайды. Мәзірде әр топ — бір отбасы, глиф 34px пастель
  плиткада.
- **Батырма** 48px r12; бір толы primary, қалғаны soft/outline (`--line-strong`).
- **Чип** — outline pill, таңдалғаны `--primary-soft` + 1px primary жиек + primary мәтін.
- **Инпут** — ақ + `--line-strong`; **іздеу** — `--surface-2` толы ұя (Kaspi/Quizlet), фокуста ақ + primary жиек.
- **Таб-бар** — ақ + hairline, белсенді: primary түс + 56×30 `--primary-soft` pill.
- **Sheet / мәзір** — ақ панель, үсті r24, тұтқа 36×5; мәзір топтары арасында hairline.
- **Бос күй** — глиф 56px `--primary-soft` дөңгелекте; **скелетон** — жиексіз `--surface-2` блоктар.
- **Иконка** — бір қалыңдық 1.8 (header-дегі 2 мен плиткадағы 30px/2 теңестірілді).
- Жаңалық карточкалары — жиексіз тұтас пастель блок (r20).

Экрандар құрылымы өзгерген жоқ (іздеу/бөлім IA мен басты беттегі hero — басқа агенттің жұмысы).

жол 44px — 844px экранға толық сыяды.

Қалған ескертулер (келесі қадамға): деталь бетінде «Google Calendar-ға қосу» 2 жолға оралады; басты беттегі
дедлайн жолында тег мәтінді қысады (календарь агентінің компоненті); профильдегі есім (28px) тақырыппен (26px)
бәсекелеседі; белсенді таб иконкасы толтырылмаған (жиында толы нұсқа жоқ); күнтізбе торы мен нативті date/time
инпуттары, басты беттегі 3D hero мен карта — басқа агенттердің аймағы.
