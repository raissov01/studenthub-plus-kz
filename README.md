# SIVA

«SIVA — веб-платформа для объединения учебных, карьерных и внеучебных возможностей студентов в единой цифровой
среде» (бұрынғы атауы Student Hub; ішкі атаулар неге `studenthub` — [`docs/BRAND.md`](./docs/BRAND.md)).

Сейфуллин университеті студенттеріне арналған қосымша: жұмыс, тағылымдама, іс-шаралар, жеңілдіктер, күнтізбе,
конспект, квиз, AI-көмекші. Next.js фронтенд + Go API + Postgres, бір VPS-те Docker Compose арқылы.

https://studenthub.studywithraissov.com
